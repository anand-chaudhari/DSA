# DSA Pattern Mastery - Interactive Mindmap

An interactive, responsive single-page web platform for mastering Data Structures and Algorithms patterns, designed to help developers and students recognize core patterns and ace technical coding interviews.

🌐 **Live Demo (GitHub Pages):** [https://anand-chaudhari.github.io/DSA/](https://anand-chaudhari.github.io/DSA/)

---

## 🌟 Key Features

- **16 Core DSA Categories & 70+ Patterns:**
  - Arrays & Two Pointers, Fast & Slow Pointers, Sliding Window
  - Trees, Graphs, Breadth-First & Depth-First Search
  - Dynamic Programming (1D, 2D, Knapsack, Intervals)
  - Backtracking, Binary Search variations
  - Heaps / Priority Queues, Tries, Disjoint Set (Union-Find)
  - Monotonic Stacks & Queues, Greedy Algorithms, Bit Manipulation
- **Interactive Mindmap & Tree View:**
  - Dynamic SVG connection lines on desktop for full visual context.
  - Collapsible/expandable categories with smooth transitions.
  - Responsive layout: transforms automatically into a touch-friendly tree structure on tablets and mobile screens.
- **Detailed Pattern Deep Dives:**
  - Clear explanations of *What it means* and *When to recognize and use it*.
  - Common clues and keywords found in problem statements.
  - Step-by-step intuition and core approaches.
  - Verified Big-O time and space complexity benchmarks.
  - Common pitfalls and mistakes to avoid.
  - Representative canonical problems (e.g. *Two Sum*, *Trapping Rain Water*, *Course Schedule*, *Alien Dictionary*, etc.).
- **Smart Learning Dashboard:**
  - Real-time overall progress percentage and category-specific progress bars.
  - Interactive checkboxes to mark patterns as completed with persistent `localStorage` support.
  - Instant live search across categories, sub-patterns, and keywords.
  - Multi-dimensional filters (Difficulty: Easy / Medium / Hard; Category; Completion status).
  - Quick action controls: "Expand All", "Collapse All", and "Reset Progress".
  - Light / Dark theme toggle with system preference auto-detection.
- **Zero-Dependency Architecture:**
  - Built entirely with vanilla HTML5, modern CSS3, and ES6 JavaScript.
  - Fully self-contained in `index.html` with zero build tools, node modules, or external frameworks needed.

## 🚀 Getting Started

### Local Setup
Simply open `index.html` in any modern web browser:
- **Windows:** Double-click `index.html` or run:
  ```powershell
  Start-Process index.html
  ```
- **macOS:**
  ```bash
  open index.html
  ```
- **Linux:**
  ```bash
  xdg-open index.html
  ```

---

## 🌐 Deploying to GitHub Pages

1. Go to your repository settings on GitHub:
   `https://github.com/anand-chaudhari/DSA/settings/pages`
2. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` and folder `/ (root)`
3. Click **Save**.
4. Your website will be live in a couple of minutes at:
   `https://anand-chaudhari.github.io/DSA/`
